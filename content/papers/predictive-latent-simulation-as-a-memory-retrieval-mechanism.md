## Abstract Snapshot
Research on hippocampal sharp-wave ripples (SWR) suggests that memory retrieval and internal simulation are deeply intertwined: prospective sequences emerge during the same neural events that drive memory access, and their content reflects expected future relevance rather than recency. Yet the computational mechanism coupling imagination to retrieval remains underspecified. We propose that imagination-guided retrieval, using internally generated latent simulations as queries against stored experience, offers a parsimonious account of this coupling. We examine navigation agents that use a world model to imagine latent future states that index persistent memory. Perfect-retrieval experiments reveal a consistent $\sim$20-point performance gap that bounds the headroom attributable to prospective simulation, and multi-agent memory sharing improves navigation in proportion to the agent pool, loosely paralleling hippocampal replay reorganized by social observation. Together, these offer testable predictions for the imagination-retrieval hypothesis.
