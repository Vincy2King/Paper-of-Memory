## Abstract Snapshot
Egocentric assistants must continuously process visual streams that can exceed practical storage and computation budgets. Human memory selectively retains goal-relevant information. Drawing on rational action and Theory-of-Mind accounts, we frame memory admission as inferring which observations are relevant to the wearer's goals from observable behavior. We present Rational Episodic Memory (REM), which uses behavioral engagement as a functional approximation of agent-centered relevance. Comparing engagement with visual surprise and uniform sampling, we nd that engagement performs best on longer recordings, whereas surprise is stronger on shorter recordings, consistent with predictive-processing and event-segmentation accounts of event boundaries.
